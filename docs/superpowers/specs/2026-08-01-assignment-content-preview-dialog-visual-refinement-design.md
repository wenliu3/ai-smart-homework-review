# 教师端作业内容预览弹窗视觉优化设计

## 背景

教师端作业详情页已经提供“查看作业内容”入口和只读弹窗，但当前弹窗存在两个问题：

1. 标题、班级、时间、正文和附件的视觉层级较弱，大面积灰色容器让内容显得沉重。
2. 视觉原型曾将富文本正文重新整理成摘要、编号标题和提示卡片，这偏离了“查看已发布内容”的真实含义。

本次优化采用已确认的“方案 A：清爽文档型”，强调色使用“清透蓝”。弹窗只优化外围信息和阅读环境，正文必须忠实呈现富文本编辑器保存的内容。

## 目标

- 保持白色阅读主体，使用清透蓝建立轻量但明确的视觉层级。
- 降低灰色边框和嵌套卡片的存在感，让弹窗更像只读文档而不是编辑表单。
- 标题、状态、班级、起止时间、正文和附件一眼可区分。
- 富文本正文按照 WangEditor 保存的 HTML 结构和格式展示，不做摘要、改写或结构转换。
- 保留现有安全过滤、附件下载、关闭弹窗和响应式行为。

## 非目标

- 不修改作业编辑器、编辑页和后端保存格式。
- 不新增作业详情接口或重复请求详情数据。
- 不在预览弹窗中加入编辑、发布、终止或保存功能。
- 不将正文自动转换为步骤列表、重点提示、代码块或其他二次排版结构。
- 不改变作业内容的业务字段和附件下载规则。

## 视觉方向

### 配色

采用固定的浅色阅读界面：

| 用途 | 色值 |
| --- | --- |
| 主强调色 | `#4F73E8` |
| 深强调色 | `#3659C7` |
| 浅强调背景 | `#F0F4FF` |
| 浅强调边框 | `#DFE7FF` |
| 主文字 | `#26324A` |
| 次要文字 | `#7B869B` |
| 中性分隔线 | `#E7EBF2` |
| 弱背景 | `#F8FAFE` |
| 弹窗主体 | `#FFFFFF` |
| 发布状态文字 | `#45A62F` |
| 发布状态背景 | `#EEF9E9` |

清透蓝只用于顶部强调线、信息图标、章节序号、下载操作和底部关闭按钮。正文区域保持白色，避免大面积蓝色干扰阅读。

### 弹窗外观

- 桌面端宽度为 `880px`，最大宽度为 `92vw`。
- 最大高度约为 `84vh`，超出后仅正文区域滚动。
- 弹窗圆角为 `14px` 至 `16px`，使用一层柔和阴影。
- 顶部增加 `4px` 清透蓝渐变强调线，方向为 `#4F73E8` 到 `#3659C7`。
- 页面遮罩保持半透明深灰色，目标值为 `rgba(15, 23, 42, 0.5)`。
- 弹窗整体只使用一个主白色表面，不为每个信息块重复增加卡片阴影。

## 信息结构

弹窗从上到下分为四个区域。

### 1. 标题区

标题区使用自定义弹窗头部：

- 左侧第一行显示书本图标和小号文字“作业内容”，使用主强调色。
- 第二行显示真实作业标题，不截断主要信息。
- 第三行显示关联班级；存在多个班级时按标签或自然换行展示，不隐藏数据。
- 右侧显示作业状态和关闭图标。
- 状态继续使用绿色，避免与蓝色功能强调混淆。

### 2. 时间信息区

- 开始时间与截止时间放在同一个浅蓝信息条中。
- 桌面端左右排列，中间使用轻量方向箭头表达时间范围。
- 每个时间项包含图标、标签和完整日期时间。
- 不改变日期值，只进行现有本地化格式化。
- 移动端改为上下排列，并隐藏中间箭头。

### 3. 正文与附件区

正文和附件继续按上下顺序展示：

1. `01 作业要求`
2. `02 作业附件`

章节序号使用浅蓝圆角方块，标题使用主文字色。章节之间仅使用细分隔线，不使用大面积灰色外框。

### 4. 底部操作区

- 底部使用弱背景 `#F8FAFE` 和顶部细分隔线。
- 左侧可显示“正文按编辑器内容原样显示”的只读提示；移动端可隐藏该辅助文字。
- 右侧保留唯一的“关闭”按钮，使用主强调色填充。
- 右上角关闭、底部关闭、`Esc` 和点击遮罩的行为保持一致。

## 富文本忠实呈现规则

### 数据来源

正文只使用 `assignmentDetail.description`。预览组件不得从正文中提取标题、编号、关键词或摘要，也不得将内容拆分成新的 Vue 模板节点。

处理流程固定为：

1. 接收后端返回的 `description` HTML 字符串。
2. 使用 DOMPurify 清除脚本、事件处理器和其他不安全内容。
3. 将过滤后的完整 HTML 一次性传给 `v-html`。
4. 浏览器按原 DOM 顺序和编辑器格式渲染。

除安全过滤外，不允许修改富文本 HTML。安全过滤可能移除危险标签或属性，这是“原样呈现”的唯一例外。

### 必须保留的格式

- 段落与空行。
- 有序列表和无序列表。
- 标题层级。
- 粗体、斜体、下划线、删除线等文本样式。
- 文本对齐、颜色等 WangEditor 生成的安全内联样式。
- 引用、行内代码、预格式化内容。
- 图片、链接和表格等编辑器允许保存的结构。
- 中文空格、英文空格及用户主动输入的缩进。

### 禁止的正文转换

- 不把普通编号段落改成 `<ol>` 或带标题的步骤行。
- 不把文本中的人物别称自动提取为蓝色提示卡片。
- 不自动添加“请按要求完成”等编辑器中不存在的说明。
- 不合并、删除或重新排序段落与空行。
- 不根据语义自动加粗、着色或添加图标。

### 展示样式边界

正文容器增加 `editor-content-view` 类，以复用项目现有的 WangEditor 回显规则；同时在弹窗局部重置该全局类自带的 `3px` 边框、外边距和容器内边距，避免再次出现厚重灰框。

弹窗局部样式只允许增加以下保护：

- `overflow-wrap: anywhere`，避免长链接撑破弹窗。
- 图片最大宽度为 `100%`，高度自动。
- 表格在窄屏下允许横向滚动，不压缩内容到不可读。
- `pre` 内容允许内部横向滚动。
- 段落和列表保留空格及换行。

这些保护不得覆盖正文中的安全内联样式，也不得改变 DOM 结构。

## 附件区

- 附件列表位于正文之后，保持独立章节。
- 单个附件行使用弱背景和细边框，不增加阴影。
- 左侧显示浅蓝文件图标，中间显示原始文件名和格式化大小，右侧显示浅蓝下载按钮。
- 文件名过长时单行省略，但保留完整可访问名称。
- 无附件时继续显示“暂无作业附件”。
- URL 缺失时禁用下载按钮；下载失败继续使用现有消息提示。

## 响应式设计

在宽度小于 `640px` 时：

- 弹窗使用接近全宽的安全边距。
- 标题区允许状态和关闭按钮换行，不覆盖标题。
- 时间信息改为上下排列。
- 章节正文取消桌面端额外左缩进，扩大阅读宽度。
- 附件名称、大小和下载按钮保持可见，必要时允许下载按钮换到下一行。
- 底部辅助提示可隐藏，仅保留关闭按钮。

## 组件与数据边界

本次只修改 `AssignmentContentPreviewDialog.vue` 及对应测试：

- `AssignmentHeader.vue` 的查看入口不变。
- 详情页 `index.vue` 的弹窗状态和数据传递不变。
- `AssignmentContentPreviewDialog.vue` 继续接收 `modelValue` 和 `assignmentDetail`。
- 不新增 API 请求，不修改后端模型。
- 附件下载逻辑保持现状。

## 错误与空状态

- `assignmentDetail` 为空时不渲染正文内容。
- `description` 为空时显示“暂无作业要求”。
- `attachments` 为空时显示“暂无作业附件”。
- 不安全富文本被过滤后为空时，同样显示“暂无作业要求”。
- 状态值未知时继续显示中性状态，不影响正文查看。

## 测试要求

### 富文本忠实性

使用代表性 WangEditor HTML 验证：

- 标题、段落、空行、列表、粗体、斜体、下划线、引用、代码、链接和表格结构仍存在。
- 原 DOM 节点顺序不变。
- 安全文本对齐和颜色样式能够保留。
- 预览组件不会生成正文摘要、步骤标题或提示卡片。
- `<script>`、内联事件和危险 URL 被移除。

### 视觉结构

- 自定义标题区显示作业标题、状态和班级。
- 时间信息条显示完整开始与截止时间。
- 正文容器同时具有弹窗正文类和 `editor-content-view` 类。
- 附件名称、大小和下载按钮正常显示。
- 空正文和空附件继续显示对应空状态。

### 回归验证

- 现有关闭事件测试继续通过。
- 详情页打开弹窗的数据流测试继续通过。
- “编辑作业”路由回归测试继续通过。
- 前端完整 Vitest、Vue TypeScript 检查和生产构建通过。
- 本地 Docker 更新后，在真实作业数据上验证正文与编辑器内容一致。

## 验收标准

- 弹窗采用白色清爽文档布局和清透蓝强调色。
- 正文可逐段对照编辑器内容，结构、顺序、空行和格式一致。
- 弹窗没有对正文做摘要、语义重排或自动强调。
- 标题、班级、时间、正文和附件视觉层级清楚，但不存在多层灰色卡片嵌套。
- 桌面端和移动端均可完整查看富文本与附件。
- 安全过滤、关闭行为、附件下载和详情页状态均无回归。
