# 学生端核心体验改版设计

## 目标

在不新增课程单元、公告、课件、讨论等业务能力的前提下，重构现有学生端学习中心、班级、作业、提交与评价页面，使信息层级、操作路径、附件体验和响应式表现接近成熟教学平台。

## 设计原则

- 保留项目蓝紫色 AI 品牌，不复制参考平台品牌、素材或红色主题。
- 只展示后端已经提供的数据；无课程封面时使用课程名称生成稳定渐变封面。
- 待办与临近截止优先于统计图表，学生首屏先看到下一步操作。
- 使用统一的间距、圆角、边框、状态色、空状态和加载反馈。
- 桌面端保持信息密度，小屏幕将表格转换为卡片或可滚动布局。

## 页面范围

### 学习中心

使用紧凑欢迎横幅、关键统计、待办作业和最近提交重组首屏。保留现有统计数据和图表，但降低图表优先级，去除标题中的装饰 emoji，统一卡片样式。

### 我的班级

将现有班级信息升级为课程卡片，展示班级名称、教师、成员或作业统计以及进入作业列表的主操作。封面由前端确定性生成，不新增数据库字段。

### 我的作业

保留现有状态筛选和查询数据，增强搜索、截止日期、成绩、提交状态与操作按钮的视觉层级。桌面端使用清晰列表，小屏幕使用卡片布局。

### 作业详情与提交

保留“作业详情 / 提交作业 / 评价结果”三个现有步骤，统一标题区、状态、截止日期和导航。作业详情显示教师附件；提交区分离正文与学生附件，并提供草稿、正式提交和错误反馈；评价区突出总分、AI 评价、教师评价、评分维度和学生附件。

## 附件数据契约

`GET /students/submissions/my/{assignment_id}` 的 `assignment` 对象补充 `attachments` 与 `allowAttachments`。前端 `Assignment` 类型同步字段，并通过共享附件组件展示文件名、类型、大小、下载动作与失败状态。该变更只暴露已存在的作业附件元数据，不新增表或上传流程。

## 组件边界

- 新建学生端共享视觉样式文件，集中页面背景、容器、卡片和状态样式。
- 新建教师作业附件列表组件，供作业详情和提交页复用。
- 现有 `AssignmentInfo`、`SubmissionForm`、`ReviewResults` 保持业务职责，只调整布局与展示。
- 不重构教师端、管理员端或全局权限逻辑。

## 测试与验收

- 后端测试锁定提交详情接口返回教师附件。
- 前端组件测试覆盖附件显示、空附件、下载行为和关键状态文案。
- 运行 Vitest、`vue-tsc --noEmit`、后端相关 pytest 与 `compileall`。
- 重建 Docker 前后端，在学生账号下对学习中心、班级、作业列表、提交三标签和附件下载进行桌面端视觉验收。
