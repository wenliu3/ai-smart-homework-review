# 教师端作业内容预览弹窗设计

## 背景

教师进入作业详情页后，目前只能通过“编辑作业”间接查看已经发布的作业要求和附件。这会把“只读查看”和“修改作业”混在同一条操作路径中，增加操作成本，也容易让教师误以为必须进入编辑状态才能确认发布内容。

## 目标

- 在作业详情页提供直接、只读的作业内容查看入口。
- 查看过程不离开当前详情页，不影响筛选条件、分页和学生提交列表状态。
- 将页面导航、常用查看操作和低频/高风险操作分层展示。
- 弹窗展示内容与学生收到的作业信息保持一致。

## 非目标

- 不在弹窗中提供编辑、发布、保存或终止功能。
- 不新增后端接口；复用详情页已经加载的作业数据。
- 不重构学生端作业详情页。
- 不调整作业发布、编辑和终止的业务规则。

## 页面操作层级

### 返回入口

“返回作业列表”属于页面导航，不与业务操作组成按钮组。它独立放在标题区域左侧，使用返回箭头和文字链接样式。

### 常用操作

详情页标题区域右侧提供一个独立按钮：

- 草稿状态：显示“预览作业内容”。
- 已发布或已终止状态：显示“查看作业内容”。

该按钮是详情页查看已发布内容的主要入口，应始终直接可见，不收进下拉菜单。

### 更多操作

“操作”下拉菜单继续承载以下功能：

- 发布作业（仅草稿状态）。
- 终止作业（仅已发布状态）。
- 编辑作业。
- 导出数据。

这些操作不使用连体按钮样式。按钮之间保留间距，避免把导航、只读查看和修改/终止操作表现为同等级选项。

## 预览弹窗

### 交互

- 点击“预览作业内容”或“查看作业内容”后，在页面中央打开模态弹窗。
- 弹窗打开时页面背景显示半透明灰色遮罩。
- 弹窗关闭后仍停留在原作业详情页，原筛选、分页和滚动状态不变。
- 支持右上角关闭按钮、底部“关闭”按钮和 `Esc` 键关闭。
- 只读弹窗允许点击遮罩关闭，不触发任何保存或业务操作。

### 尺寸与滚动

- 桌面端宽度约为 `800px`，同时设置视口自适应最大宽度。
- 弹窗最大高度约为视口的 `80vh`。
- 内容超过最大高度时，仅弹窗内容区域滚动，页面背景保持固定。
- 移动端使用接近全宽的布局，并保留安全边距。

### 展示内容

弹窗按以下顺序展示：

1. 作业标题和当前状态。
2. 关联班级。
3. 开始时间和截止时间。
4. 作业要求（按发布时的富文本格式只读渲染）。
5. 作业附件列表，包括文件名、文件大小和下载按钮。

没有作业描述时显示“暂无作业要求”；没有附件时显示“暂无作业附件”，避免出现空白区域。

### 数据流

详情页已经通过 `getAssignmentDetail(assignmentId)` 获得标题、描述、状态、班级、时间和附件。弹窗直接接收当前 `assignmentDetail`：

1. `AssignmentHeader` 发出 `preview` 事件。
2. 详情页收到事件后将弹窗可见状态设为 `true`。
3. 预览组件接收 `assignmentDetail` 并只读渲染。
4. 关闭弹窗只修改本地可见状态，不重新请求接口。

## 组件边界

### `AssignmentHeader.vue`

- 负责展示返回、查看内容和操作入口。
- 根据作业状态计算按钮文案。
- 点击查看按钮时只发出 `preview` 事件，不持有弹窗状态。

### `AssignmentContentPreviewDialog.vue`

- 负责模态弹窗、遮罩、内容布局、空状态和附件下载入口。
- 通过 `modelValue` 控制显示/隐藏。
- 接收 `AssignmentDetail | null`，不主动请求数据。
- 不包含任何编辑或状态变更逻辑。

### 详情页 `index.vue`

- 持有弹窗可见状态。
- 连接 `AssignmentHeader` 的 `preview` 事件与预览弹窗。
- 将当前 `assignmentDetail` 传给预览弹窗。

## 错误和边界处理

- 详情数据仍在加载时，查看按钮禁用，避免打开无内容弹窗。
- 附件 URL 缺失时禁用对应下载按钮。
- 附件下载沿用现有 URL 处理规则；下载失败时显示错误提示。
- 富文本按项目现有安全渲染方式处理，不引入新的不受信任 HTML 执行路径。
- 已终止作业仍可查看其最终发布内容。

## 测试要求

- `AssignmentHeader` 在草稿状态显示“预览作业内容”，在已发布/已终止状态显示“查看作业内容”。
- 点击按钮会发出一次 `preview` 事件。
- 详情页收到事件后打开弹窗，并传入当前作业详情。
- 弹窗渲染作业要求、班级、时间和附件。
- 描述或附件为空时显示对应空状态。
- 关闭弹窗不会触发接口请求或页面导航。
- 原有“编辑作业”跳转回归测试继续通过。

## 验收标准

- 教师无需进入编辑页即可查看已经发布的作业内容。
- 弹窗打开时背景变灰，内容在弹窗内部滚动。
- 关闭弹窗后仍处于原详情页，页面状态未丢失。
- 页面只保留一个直接可见的查看内容按钮；编辑、终止和导出继续位于操作菜单。
- 桌面端和移动端均可完整查看作业描述与附件。
