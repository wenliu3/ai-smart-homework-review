# AI 助手运行预算调整设计

## 目标

将教师、学生和管理员交互式 AI 助手共用的默认单次运行总预算从 45 秒调整为 10 分钟（600 秒），避免多节点串行模型调用在正常完成前被总预算中断。

## 边界

- 仅调整 `default_run_budget()` 的 `timeout_seconds`。
- 保持通用模型和审核模型的单次请求超时为 40 秒。
- 保持节点上限 8、工具调用上限 12、模型调用上限 12。
- 保持异步批改任务的 120 秒专用预算不变。

## 验证

更新默认预算契约测试，使其明确断言 600 秒；运行 Agent 运行时单元测试及后端语法检查。
