# 学生端滚动与班级卡片修复设计

## 背景

学生端提交工作区在桌面布局中无法继续向下滚动，长作业说明和提交区域会被页面底部截断。班级列表卡片还会把班级名前两个字作为封面文字，例如“自然语言处理（NLP）”额外显示“自然”，形成重复信息。

## 根因

- `AppLayout.vue` 已将路由根元素设置为唯一的滚动容器，但提交页后置样式把 `.submission-container` 覆盖为 `height: auto` 和 `overflow: visible`。该元素所在的父级是 `overflow: hidden`，因此超出视口的内容被截断。
- `ClassList.vue` 的 `getClassInitials()` 会截取班级名前两个字，放进 72px 高的渐变封面；完整班级名又在卡片正文重复显示。

## 设计

### 提交工作区

保持 `AppLayout` 的单滚动容器模型，不新增嵌套滚动条。提交页根元素改为占满可用高度，并负责纵向滚动：

- `height: 100%`
- `min-height: 0`
- `overflow-y: auto`
- `overflow-x: hidden`

标签页和内容卡片继续使用自然高度，长作业详情、附件区、编辑器和底部操作按钮都随页面滚动。

### 班级卡片

删除 `getClassInitials()` 及封面里的文字和班级编号。原 72px 封面缩减为一条细蓝紫渐变装饰带；卡片正文继续展示一次完整班级名称、状态、教师和人数，不新增字段或交互。

## 验证

- 前端回归测试：提交工作区根节点保留纵向滚动契约；班级卡片不再渲染由名称截取的“自然”，完整班级名只出现一次。
- 类型检查与前端全量测试通过。
- 浏览器复测：使用学生账号从“我的班级”点击“开始作业”，确认能滚动到作业说明底部、提交页底部和操作按钮；确认班级卡片不再出现多余的“自然”。

## 范围

仅修改学生端提交工作区布局、班级卡片展示及其测试；不修改后端接口、数据模型、作业流程或其他角色页面。
